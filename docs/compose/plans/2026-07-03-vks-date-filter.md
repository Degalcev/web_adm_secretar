# Переделка фильтра дат на страницах VKS

## Текущее состояние
- Один инпут `type="date"` — выбирает конкретный день
- Нет возможности фильтровать по месяцу или году отдельно

## Предлагаемое решение
Три селекта: **День** (1-31 или Все) + **Месяц** (январь-декабрь или Все) + **Год** (2024-2027 или Все)

Фильтрация по комбинациям:
- Только год → все события за год
- Год + месяц → все события за месяц
- Год + месяц + день → конкретный день
- Только день → этот день во всех месяцах

## Файлы
- `app/static/index.html` — замена инпута日期 на 3 селекта (active + completed)
- `app/static/js/vks.js` — логика фильтрации по трем полям, сброс
- `app/static/css/filters.css` — стили для селектов (если нужно)
