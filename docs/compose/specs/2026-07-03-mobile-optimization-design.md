# Спецификация: Мобильная оптимизация web_adm_secretar

> [!NOTE]
> This document may not reflect the current implementation.
> See the final report for up-to-date state:
> [Final Report](../reports/mobile-optimization.md)

## [S1] Проблема

Панель администратора не оптимизирована для мобильных устройств. При просмотре на экранах < 768px:
- Sidebar скрыт без альтернативы навигации
- Таблицы обрезаются без возможности прокрутки
- Фильтры VKS выходят за границы экрана
- Top bar не адаптирован
- Формы в модалках не перестраиваются

## [S2] Брейкпоинты

| Breakpoint | Описание |
|---|---|
| `<= 768px` | Планшет / вертикальный — sidebar скрыт, гамбургер-меню |
| `<= 480px` | Мобильный — уплотнение интерфейса |

Существующий брейкпоинт 768px сохраняется. Добавляется 480px для мелких экранов.

## [S3] Мобильное меню (навигация)

**Решение:** Гамбургер-иконка в topbar, при нажатии — overlay с навигацией.

- Добавить кнопку `.mobile-menu-btn` в `topbar-left` (скрыта на десктопе)
- При клике — показать overlay с содержимым sidebar
- Закрытие: клик по overlay, свайп влево, кнопка закрытия
- Анимация: slide-in слева (0.2s)
- На уровне HTML: добавить кнопку в `index.html`
- На уровне JS: добавить обработчики в `navigation.js`
- На уровне CSS: стили для overlay и кнопки в `responsive.css`

## [S4] Таблицы

**Решение:** Горизонтальный скролл для контейнера таблицы.

- `.table-wrap` добавить `overflow-x: auto`
- Минимальная ширина таблицы `600px` чтобы колонки не сжимались
- На планшетах (<= 768px): скрыть колонку "дата создания" если есть

## [S5] Фильтры VKS и общие

**Решение:** Фильтры перестраиваются в вертикальный стек на мобильных.

- `.filter-bar`: на <= 768px `flex-direction: column`
- `.filter-group`: `min-width: 100%`
- `.filter-date-group`: `min-width: auto`, `width: 100%`
- `.filter-date-selects`: `flex-wrap: wrap`

## [S6] Top bar

**Решение:** Уплотнение top bar на мобильных.

- <= 768px: скрыть `topbar-version`, уменьшить padding
- <= 480px: скрыть `topbar-datetime` или показать только время (без даты)
- Добавить гамбургер-кнопку (см. S3)

## [S7] VKS карточки

**Решение:** Упрощение левого блока на мобильных.

- <= 768px: `.vks-card-left` убрать border-right, уменьшить min-width до 48px
- <= 480px: `.vks-card` перейти в column layout, `.vks-card-left` стать горизонтальной строкой сверху

## [S8] Модалки и формы

**Решение:** Адаптивные формы.

- `.form-row`: на <= 768px `flex-direction: column`
- Модалки: существующие правила сохраняются, 추가ить `max-height: 85vh`
- `.modal-body`: уменьшить padding на мобильных

## [S9] Дашборд

**Решение:** Существующие правила уже работают (4→2→1 колонки). Дополнительно:

- <= 480px: `.dash-chart-bars` уменьшить `height` до 140px
- `.dash-row-locs`: на <= 768px `grid-template-columns: 1fr` (уже есть)

## [S10] Логи

**Решение:** Существующие правила работают. Дополнительно:

- `.log-container`: на <= 768px `min-height: 200px`
- `.log-footer`: на <= 480px `flex-direction: column`, `gap: 4px`

## [S11] Файлы для изменения

| Файл | Изменения |
|---|---|
| `app/static/css/responsive.css` | Основной файл — все медиа-запросы |

## [S12] Что НЕ меняем

- API маршруты
- Авторизацию
- SSE
- Темы оформления
- Desktop версию (все правила в медиа-запросах)
