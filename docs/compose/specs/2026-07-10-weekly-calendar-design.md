# Спецификация: Календарь мероприятий на неделю

**Дата**: 2026-07-10
**Статус**: черновик

---

## Цель

Недельный календарь VKS с распределением по залам и времени. Наглядное отображение пересечений.

---

## Макет

Grid-раскладка:
- **Столбцы** = локации (залы). Первый столбец — шкала времени (06:00–23:00)
- **Строки** = часы (06:00, 07:00, ... 22:00). Высота строки: 60px
- **Ячейка** = пересечение зал × время

```
┌──────────┬──────────┬──────────┬──────────┐
│  Время   │  Зал 1   │  Зал 2   │  Зал 3   │
├──────────┼──────────┼──────────┼──────────┤
│  06:00   │          │          │          │
│  07:00   │          │          │          │
│  08:00   │ [ВКС]    │          │          │
│  09:00   │          │ [Совещ]  │          │
│  ...     │          │          │          │
│  22:00   │          │          │          │
└──────────┴──────────┴──────────┴──────────┘
```

---

## Позиционирование событий

Событие позиционируется точно по времени:
- `top` = `(час - 6) * 60px + (минуты / 60) * 60px`
- `height` = `duration * 60px` (по умолчанию 60px если нет end time)
- Для события 15:30: `top = (15-6)*60 + (30/60)*60 = 540 + 30 = 570px`

События в одной ячейке (один зал, одно время) — flex-row,每个 событие с `flex: 1`.

---

## Навигация

- Кнопки ← / → для переключения недель
- Кнопка «Сегодня» — возврат к текущей неделе
- Заголовок: «7 – 13 июля 2026»
- Дни недели: Пн 07, Вт 08, ... Вс 13

**Примечание:** Календарь показывает ОДНУ неделю. Столбцы — это НЕ дни, а локации. Дни недели отображаются в заголовке (переключатель).

---

## Карточка события

```css
.cal-event {
    position: absolute;
    left: 2px; right: 2px;
    border-radius: 4px;
    padding: 4px 6px;
    font-size: 0.6875rem;
    overflow: hidden;
    cursor: pointer;
}
```

Содержимое:
- **Цветовая полоска** (left border 3px): accent (ВКС), success (завершено), muted (другое)
- **Тип** (жирный)
- **Организатор** (muted)
- **Описание** (если влезает, обрезается через ellipsis)

---

## Пересечения

Два+ события в одном зале в одно время:
```css
.cal-cell-events {
    display: flex;
    gap: 2px;
    height: 100%;
}
.cal-event {
    flex: 1;
    min-width: 0;
}
```

---

## Текущее время

Красная горизонтальная линия через весь календарь:
```css
.cal-now-line {
    position: absolute;
    left: 0; right: 0;
    height: 2px;
    background: var(--danger);
    z-index: 5;
}
.cal-now-line::before {
    content: '';
    position: absolute;
    left: -4px; top: -4px;
    width: 10px; height: 10px;
    border-radius: 50%;
    background: var(--danger);
}
```

Обновляется каждую минуту через `setInterval`.

---

## Клик по событию

Вызывает `openEditEventModal(eventId)` — ту же модалку что и на VKS доске.

---

## Данные

Из `store.allEvents`. Фильтрация по неделе на клиенте:
```js
const weekEvents = store.allEvents.filter(e => {
    const d = new Date(e.date);
    return d >= weekStart && d <= weekEnd;
});
```

## Интеграция

- **Sidebar**: новая страница «Календарь» в навигации
- **Router**: маршрут `/calendar`
- **index.html**: подключение calendar.css и calendar.js
- **SSE**: календарь обновляется через существующий `store.allEvents` refresh

---

## Тестирование

1. Открыть календарь → видно текущую неделю
2. Переключить неделю → события обновляются
3. Событие в 15:30 → позиция в середине строки 15:00
4. Два события в одном зале → стоят рядом
5. Клик по событию → открывается модалка VKS
6. Линия текущего времени отображается и обновляется
