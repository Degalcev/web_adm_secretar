### Оптимизации
- Preload API: 1 запрос вместо 3
- Batch загрузка документов: `WHERE event_id = ANY($1)`
- Cursor-based пагинация (бэкенд)
- Session validation через JOIN
- SSE debounce 300ms
- LocalStorage кэш для мгновенной загрузки

## Осталось выполнить

### Важное
| # | Задача | Сложность | Описание |
|---|--------|-----------|----------|
| 1 | Печать на PDF | Средняя | Заменить HTML-генерацию в `print.js` на PDF (решает XSS). Использовать `window.print()` с `@media print` или jsPDF |
| 2 | Статистика active/completed | Лёгкая | `eventsUpdateStats()` не учитывает режим страницы — всегда считает active. Нужно фильтровать по `_eventsCompleted` |
| 3 | Generic ошибки | Лёгкая | `str(e)` в `vks.py:199` утечка внутренних ошибок клиенту. Заменить на generic "Ошибка сервера" |

| # | Задача | Сложность | Описание |
|---|--------|-----------|----------|
| 4 | Константа EVENTS_LIMIT | Лёгкая | `limit=10000` захардкожен в 4 файлах. Вынести в `utils.js` |
| 5 | Мёртвый CSS | Лёгкая | `.events-tabs`, `.events-tab` в `events.css` — не используются |
| 6 | try/catch в eventsRenderBoard | Лёгкая | Защита от malformed данных при рендеринге карточек |
